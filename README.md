# Drive2-assistant

RAG-помощник по статьям Drive2.ru. Отвечает на вопросы, синтезируя опыт
реальных автовладельцев из статей и комментариев.

## Идея проекта

Сейчас на Drive2 поиск работает по ключевым словам: пользователь вводит
запрос и получает список статей. Но часто нужен не список, а **ответ**:
«какие зимние шины советуют на Kia Rio?», «как подключить подогрев сидений
к сигнализации?».

**Drive2-assistant** — это AI-помощник, который:
1. Ищет релевантные фрагменты в статьях и комментариях.
2. Синтезирует аналитический ответ на основе опыта авторов.
3. Указывает источники — пользователь может проверить.

## Демонстрация

Пример работы:

```
Вы: Какую резину советуют на Kia Rio?

Ответ:
На основе опыта авторов Drive2 для Kia Rio рекомендуются:
- Hankook W419 — мягкая, тихая, с шипами
- Bridgestone Blizzak — хорошее сцепление на льду
- Nokian Hakkapeliitta 8 — универсальная, но шумнее
Размер 185/65 R15 подходит большинству моделей.

ИСТОЧНИКИ:
• Зимние шины ❄️ (drive2.ru/l/511518099082576618)
• Выбор зимних шин (2021) KIA RIO (drive2.ru/l/598217064833900606)
• Зимние шины для KIA RIO (drive2.ru/l/484995954475270162)
```

## Стек

| Компонент | Что используется |
|---|---|
| Сбор данных | Playwright (headless Chromium) |
| Парсинг HTML | BeautifulSoup + lxml |
| Эмбеддинги | intfloat/multilingual-e5-small |
| Векторная БД | ChromaDB |
| LLM | Ollama + Qwen2.5 |
| Язык | Python 3.12 |

## Структура

```
drive2-assistant/
├── config.py                  # настройки (User-Agent, паузы, пути)
├── collect_playwright.py      # автоматический сбор статей
├── collect_specific.py        # сбор конкретных URL из my_urls.txt
├── parse_html.py              # HTML → JSON (пост + комментарии)
├── indexer.py                 # JSON → ChromaDB (эмбеддинги)
├── search.py                  # RAG-поиск + Ollama
├── heating_qa.py              # отдельный Q&A по подогреву сидений
├── data/
│   ├── raw/                   # HTML-файлы (59 шт.)
│   ├── articles/              # JSON с постом и комментариями
│   └── articles_map.json      # карта filename → URL
├── chroma_db/                 # векторная БД
├── my_urls.txt                # список URL для сбора
└── README.md
```

## Установка

```bash
# Виртуальное окружение
python3 -m venv .venv
source .venv/bin/activate
pip install --upgrade pip

# Зависимости
pip install -r requirements.txt

# Playwright Chromium
playwright install chromium

# Ollama + модель
curl -fsSL https://ollama.com/install.sh | sh
ollama pull qwen2.5:3b
```

## Запуск

### 1. Сбор статей

**Автоматически** (по поисковым запросам из `config.py`):
```bash
python collect_playwright.py
```

**Конкретные URL** (из `my_urls.txt`):
```bash
python collect_specific.py
```

### 2. Парсинг HTML → JSON

```bash
python parse_html.py
```

### 3. Индексация в ChromaDB

```bash
python indexer.py
```

### 4. RAG-поиск

```bash
python search.py
```

Введите вопрос, получите ответ с источниками. Выход — `выход`.

### 5. Q&A по отдельной теме (подогрев сидений)

```bash
python heating_qa.py
```

## Данные

Собрано **59 статей** с Drive2.ru:

- **Тема:** зимние шины для Kia Rio, Lada Vesta, Hyundai Solaris, Toyota Camry, VW Polo.
- **Дополнительно:** 3 статьи про подогрев сидений после автозапуска.
- **Объём:** ~239 чанков в ChromaDB.

Каждая статья содержит:
- Пост (текст автора).
- Комментарии (опыт десятков автовладельцев).

## Как работает RAG

```
Вопрос пользователя
    ↓
[1] Эмбеддинг вопроса (multilingual-e5-small)
    ↓
[2] Поиск топ-K чанков в ChromaDB (косинусное сходство)
    ↓
[3] Передача чанков в LLM (Qwen2.5 через Ollama)
    ↓
[4] Генерация ответа + список источников
```

## Масштабирование

Для добавления новых статей:
1. Собрать HTML → `data/raw/`.
2. Запустить `parse_html.py`.
3. Запустить `indexer.py`.
4. Изменять код **не нужно**.

Для интеграции с Drive2.ru:
- Официальный доступ к БД вместо парсинга.
- PostgreSQL + pgvector вместо ChromaDB.
- GPU-инференс (сейчас 10–15 сек на ответ на CPU).
- API для фронтенда.

## Ограничения

- **Скорость:** 10–15 секунд на ответ на CPU.
- **Модель:** Qwen2.5:3b — не самая мощная, иногда обрывает ответ.
- **Данные:** 59 статей — демо-объём. Для продакшена нужно 1000+.

## Демонстрация для создателей Drive2

В папках `demo/` и `extension/` — материалы для показа:

### 1. HTML-макет

`demo/mockup.html` — статичный макет главной страницы Drive2 с кнопкой
AI-помощника. Показывает, как это будет выглядеть.

**Как запустить:**

```bash
cd demo
python3 -m http.server 8000
```

Открой: `http://localhost:8000/mockup.html`

### 2. Браузерное расширение (proof of concept)

`extension/` — Chrome-расширение, которое **добавляет кнопку AI-помощника
на настоящий Drive2.ru** при открытии сайта.

**Как установить:**

1. Открой Chrome: `chrome://extensions/`
2. Включи «Режим разработчика»
3. Нажми «Загрузить распакованное расширение»
4. Выбери папку `extension/`
5. Открой `https://drive2.ru` — кнопка появится рядом с поиском

**Важно:** Streamlit должен быть запущен на `http://localhost:8501`:

```bash
streamlit run app.py \
    --server.enableCORS=false \
    --server.enableXsrfProtection=false
```

При клике на кнопку открывается модальное окно с работающим AI-помощником.
